The routine this queue serves

Stop doing

  • Daily LeetCode — Codeforces already covers it
  • Picking issues because nobody is looking at them
  • Docs as a day's output (one per fortnight, bundled)
  • Opening a new PR while one is still open

Start doing

  • One PR at a time, worked until merged or killed
  • Post your reproduction on the issue before writing code
  • Log one measurement a day: what, the number, what it means
  • Saturday depth block — SPSC ring buffer, then #124444
  • Apply to three roles a month, from month one
