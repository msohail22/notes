## Conventions

- One file per change, named `NN-what-changed.md`, in the order it happened.
- Record the **state before**, the command run, and the state after. A note that only
  lists commands cannot be checked later.
- Paste the real output, not a tidied version. The error text is the useful part.
- Name the hardware and the versions. `systemd 258` and `systemd 254` fail differently.
- A change that needed a rollback is worth more than one that worked. Write that one down.
